Installation

  1. Download and open the .dmg file
  2. Drag Chowser to Applications
  3. Launch Chowser — it appears in the menu bar
  4. Right-click → Open if macOS shows a security warning
  5. Set Chowser as your default browser when prompted
Note: This build is unsigned. On first launch, right-click → Open to bypass Gatekeeper.
