The Full AI Prompt

Paste this directly into Claude, ChatGPT, Cursor, or any AI with file system access

chowser-setup-prompt.md 
I have installed Chowser (bundle ID: in.sreerams.Chowser) on my Mac.
It's a browser chooser app that intercepts links. I need you to:

## Step 1: Discover my browsers and profiles

Scan my Mac for all installed browsers and their profiles:

- Chromium browsers (Chrome, Brave, Edge, Vivaldi, Arc, Dia, Opera):
  Check ~/Library/Application Support/{BrowserName}/Local State
  Parse the JSON → profile.info_cache → each key is a profile directory name
  (e.g. "Default", "Profile 1", "Profile 2")

- Firefox-based (Firefox, Zen, LibreWolf, Waterfox):
  Check ~/Library/Application Support/{BrowserName}/profiles.ini
  Parse INI → each [Profile*] section → Name= is the profile name

- Safari: No profiles, just add it as-is.

For each browser+profile combo, produce a JSON object:
{ "name": "Chrome - Work", "bundleId": "com.google.Chrome", "shortcutKey": "1", "profile": "Profile 1" }

Assign shortcutKeys "1" through "9" in order.
Save ALL as ChowserBrowsers.json.

## Step 2: Generate routing rules

Based on my needs: [EDIT THIS — e.g. "work stuff in Chrome Work profile, personal browsing in Safari, dev docs in Firefox"]

For each rule:
{ "name": "Work GitHub", "hostPattern": "*.github.com", "pathPrefix": "/my-org", "browserBundleId": "com.google.Chrome", "profile": "Profile 1", "isEnabled": true, "usePrivateMode": false }

hostPattern: exact (github.com) or wildcard (*.github.com)
pathPrefix: optional, only for path-level routing
usePrivateMode: set true if you want this rule to always open incognito

Save ALL as ChowserRules.json.

## Step 3: Import into Chowser

Tell me to open Chowser → Menu Bar Icon → Settings:
- Browsers tab → ⋯ menu → Import Browsers → select ChowserBrowsers.json
- Rules tab → ⋯ menu → Import Rules → select ChowserRules.json

Why Use This?

Profile Discovery

Browser profile directory names like "Profile 1" or "Default" are buried deep in your file system — tedious to find manually. Your AI reads them in seconds.

Rule Generation

Describe your workflow in plain English. The AI generates ready-to-import JSON routing rules that match how you actually work — no manual JSON editing required.
