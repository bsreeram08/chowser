# Issues and Gotchas

## Known Issues
- Electrobun doesn't support Windows 10 officially (but works with WebView2)
- No NSIS/MSI or AppImage/deb packaging available
- No global shortcuts API in Electrobun
- No code signing API in Electrobun

## Workarounds
- Manual implementation may be needed for code signing later
- Self-extracting archives acceptable for distribution
