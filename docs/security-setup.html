Allow Chowser
on macOS

Because Chowser isn't yet signed with an Apple Developer certificate, macOS blocks the very first launch. These three steps take under 60 seconds and only need to be done once.

1 · Right-click → Open
2 · Privacy → Open Anyway
3 · Set as Default Browser
1

Right-click the app to Open

After dragging Chowser to Applications, do not double-click — macOS will refuse outright. Instead, right-click (or Control-click) the icon and choose Open. This unlocks a special prompt that double-clicking never triggers.

On a trackpad: two-finger tap. On a Magic Mouse: hold Control while clicking.

2

Open Anyway in System Settings

macOS will briefly show a "can't be opened" alert. Go to System Settings → Privacy & Security and scroll to the bottom. You'll see a notice that Chowser was blocked — click Open Anyway and confirm with your password or Touch ID.

The "Open Anyway" button disappears after one hour, so do this soon after the first blocked attempt.

Set Chowser as Default Browser

Open System Settings → General and change the Default web browser dropdown to Chowser. Alternatively, click the Chowser menu bar icon and choose Set as Default Browser. Every link you click will now route through Chowser.
