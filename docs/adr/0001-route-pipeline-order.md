# Route pipeline order: rewrites → shortlink resolution → tracking cleanup

Advanced Routing adds typed URL rewrite rules ahead of the existing shortlink-then-cleanup pipeline. We considered running cleanup before shortlink resolution (rewrites → cleanup → shortlink) so cleanup could strip tracking params before any network call — but tracking params usually live on the *expanded* URL, not the shortlink wrapper, so cleanup would run on the wrong URL and do nothing useful. We chose **rewrites → shortlink → cleanup**: local rewrites run first (cheap, no network, may pre-empt the need to unshorten at all), then shortlink resolution expands the real URL, then cleanup strips tracking params from that real URL. This preserves today's shortlink→cleanup relationship and only inserts rewrites at the front.
