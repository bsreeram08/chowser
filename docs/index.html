Get Started in 4 Steps

Up and running in under two minutes. Chowser lives quietly in your menu bar.

1

Download & Install

Download the latest .dmg from GitHub Releases. Open it and drag Chowser into your Applications folder.

2

Bypass Security Warning

Because this is an unsigned build, macOS blocks the first launch. Right-click (Control-click) the app and choose Open, then confirm.

View detailed security guide →
3

Set as Default Browser

Click the Chowser menu bar icon → Set as Default Browser. Chowser will now intercept every link you click.

4

Configure & Customize

Open Settings from the menu bar icon. Add browsers, select specific profiles, and configure routing rules to auto-launch the right browser.

Smart Routing Rules

Set up powerful rules to auto-route specific domains to work, personal, or testing browsers — no picker needed.

How Rules Work

Rules run top-to-bottom. When you click a link, Chowser checks each rule in order — the first match wins and opens the URL directly in the assigned browser. No match falls back to the picker.

  • Domain Matching

    Match exact domains or use wildcards — *.google.com catches all subdomains.

  • Path Prefix

    Fine-grained control with path matching — e.g. /my-org routes only your org's repos.

  • App-Based Routing

    Route by source app — links from Slack open in Chrome Work, links from Terminal open in Firefox Dev.

What's in v2.6.1

More power, less clutter. Every feature power users asked for, built in.

Browser Profiles

Full support for Chrome, Brave, Edge and Firefox profiles. Route work links to your work profile and personal links to your home profile automatically.

Arc & Dia: profiles are detected and shown, but these browsers don't support switching profiles via CLI — links will open in the default profile.

Private Mode

Press P or click the eye button to toggle private mode. Session-scoped — all subsequent launches open incognito until you toggle off.

App-Based Routing

Route by which app opened the link. Links clicked in Slack go to Chrome Work. Links from Terminal go to Firefox Dev. Fully configurable per source app.

Smart Rules

Domain + path matching with wildcard support. Matching rules auto-launch without showing the picker. Drag to reorder, toggle enable/disable per rule.

Clipboard Quick Actions

Open a URL from your clipboard directly via the menu bar icon — no need to click a link. Works for both normal and private mode browsing.

Rule Portability

Import and export your browser configs and routing rules as JSON. Share your setup across machines or back it up with a single click from the Settings menu.
